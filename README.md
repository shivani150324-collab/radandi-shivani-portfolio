# Radandi Shivani - Personal Portfolio

## Technologies
- HTML5
- CSS3
- Bootstrap 5
- JavaScript (ES6+)
- Bootstrap Icons

## Features
- Semantic portfolio sections
- Responsive mobile-first layout
- Bootstrap navbar, grid, buttons, cards, forms and alerts
- Light/dark theme switching
- Skill filtering using DOM manipulation
- Contact-form client-side validation
- Dynamic success/error messages
- Smooth navigation and back-to-top button
- Accessible focus styles and skip link
- Reduced-motion support

## Run locally
No build step is required.

1. Extract/open this folder.
2. Open `index.html` in a browser.
3. For the best development experience, use VS Code with Live Server.

## Important content note
The content is based on the supplied Resume PDF and the FSD Assignment-1 requirements. A separate LinkedIn Profile PDF was not supplied in the current upload, so the LinkedIn URL used here is the one already present in the Resume PDF.

## GitHub
Create a repository and upload:
- index.html
- style.css
- script.js
- README.md
- assets/

Then enable GitHub Pages if a live deployment is required.

## Vercel
This project is static and can be deployed by importing the GitHub repository into Vercel. No build command is required.
